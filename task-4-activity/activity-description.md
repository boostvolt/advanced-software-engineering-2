# Proposal: "Code Showdown" – Human vs. AI Class Activity

## 1. Executive Summary
* **Duration:** ~5-10 Minutes
* **Focus:** Code Quality, Readability, and Maintainability (Java)
* **Core Objective:** Shift student focus from "Does this code work?" to "Is this code clean, readable, and maintainable?" by comparing identical algorithms written by a human and an AI.

## 2. The Concept
We present students with two anonymous, working solutions to the standard "Valid Sudoku" problem. Both have identical Big-O time and space complexity. Students evaluate the snippets side-by-side, vote on which is "Better" for a production environment, and guess which one was generated by an AI. 

This creates an immediate, engaging debate about coding standards, variable naming, and control flow.

---

## 3. The Task: Valid Sudoku from LeetCode
**Prompt given to the solvers:**
Determine if a **9 x 9 Sudoku board** is valid. Only the filled cells need to be validated according to the following rules:
1. Each row must contain the digits `1-9` without repetition.
2. Each column must contain the digits `1-9` without repetition.
3. Each of the nine `3 x 3` sub-boxes of the grid must contain the digits `1-9` without repetition.

*(Note: A Sudoku board could be valid but is not necessarily solvable. Only the filled cells need to be validated.)*

---

## 4. The Artifacts (To be shown side-by-side)

### Snippet A (The Human - Competitive Programming Style)
```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        boolean[][] rows = new boolean[9][9];
        boolean[][] cols = new boolean[9][9];
        boolean[][] boxes = new boolean[9][9];

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = board[i][j] - '1';
                    int boxIndex = (i / 3) * 3 + (j / 3);

                    if (rows[i][num] || cols[j][num] || boxes[boxIndex][num]) {
                        return false;
                    }

                    rows[i][num] = cols[j][num] = boxes[boxIndex][num] = true;
                }
            }
        }
        return true;
    }
}
```

### Snippet B (The AI - Clean Code Style)
```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // Initialize 2D boolean arrays to track seen numbers
        // rows[i][j] means "in row i, has the number j+1 been seen?"
        boolean[][] rows = new boolean[9][9];
        boolean[][] cols = new boolean[9][9];
        boolean[][] boxes = new boolean[9][9];

        for (int r = 0; r < 9; r++) {
            for (int c = 0; c < 9; c++) {
                if (board[r][c] == '.') {
                    continue; // Skip empty cells
                }

                // Convert char '1'-'9' to an integer index 0-8
                int val = board[r][c] - '1'; 
                
                // Calculate the 1D index of the 3x3 sub-box (0 to 8)
                int boxIdx = (r / 3) * 3 + (c / 3);

                // If the value has already been seen in the current row, col, or box, it's invalid
                if (rows[r][val] || cols[c][val] || boxes[boxIdx][val]) {
                    return false;
                }

                // Mark the number as seen
                rows[r][val] = true;
                cols[c][val] = true;
                boxes[boxIdx][val] = true;
            }
        }
        
        return true;
    }
}
```
